# SamboTL — инструкция по установке и запуску

Система для проведения турниров по самбо. Работает полностью **офлайн**, в локальной
сети Windows-компьютеров: один ПК — **сервер**, остальные подключаются к нему.

---

## 1. Что вам понадобится

| Компонент | Где взять |
|-----------|-----------|
| `SamboTLServer.exe` | собирается из проекта (`packaging\build.ps1`) |
| `SamboTLClientSetup.exe` (установщик клиента) | собирается через Inno Setup |
| Компьютер-сервер (Windows 10/11) | организаторский ПК |
| Компьютеры операторов (Windows) | для взвешивания, судейства, табло |
| Телевизоры/мониторы с HDMI | для табло и расписания |
| Microsoft Edge WebView2 Runtime | обычно уже установлен (см. раздел 6) |

---

## 2. Установка сервера

Сервер — это **портабельный `.exe`**, установка не требуется:

1. Скопируйте `SamboTLServer.exe` в отдельную папку (например, `D:\SamboTLSrv`).
2. Запустите его двойным щелчком (или по ярлыку на рабочем столе).
3. Откроется **панель сервера** — окно, где всё видно и понятно.

> Данные турниров (`data\`) создаются **рядом с .exe** в этой же папке.
> Чтобы перенести всё на другой компьютер, просто скопируйте папку целиком.

---

## 3. Панель сервера — что здесь есть

Окно панели содержит три блока:

### 3.1 Запуск/остановка
- **Порт** — по умолчанию `8000` (менять не нужно, если не занят).
- **Адрес приёма** — `0.0.0.0` (слушать всю локальную сеть).
- Кнопка **«Запустить сервер»** — включает сервер.
- После запуска внизу появится блок с данными:
  - адрес, который клиенты открывают в локальной сети: `http://<IP-сервера>:8000/app/`;
  - **пароль доступа к экранам**;
  - логин/пароль **админки** (по умолчанию `admin / admin1234`).

### 3.2 Турниры
- Список всех турниров (каждый — отдельный файл базы).
- Клик по турниру делает его **активным** (сервер обслуживает именно его).
- Кнопка **«Новый турнир»** открывает форму создания.

### 3.3 Создание турнира
Заполните:
- **Название** — например, «Кубок города 2026».
- **Система** — «Олимпийская» или «До 6 ошибок».
- **Аудитория** — «Взрослые» / «Дети» / «Смешанный».
- **Ковров** — число ковров (обычно 3–4).
- **Пароль доступа к экранам** — тот, который операторы вводят в клиенте.
- **Пароль админки** — для входа в админку (по умолчанию `admin1234`).

После создания турнир сразу становится активным.

### 3.4 Доступ к активному турниру
Блок показывает текущие пароли активного турнира и позволяет их **сменить**
(поле «Новый пароль экранов» / «Новый пароль админки» → «Применить»).

> **Пароли хранятся рядом с сервером** (в папке `data\server_credentials.json`)
> и показываются только организатору на его серверном ПК.

## 4. Установка клиента (для операторов)

Клиент нужен на компьютерах, где будут **взвешивание, судейство, табло, расписание**.

### Вариант А — установщик (рекомендуется)

1. Запустите `SamboTLClientSetup.exe`.
2. Пройдите мастер установки (язык русский/английский).
3. Установщик создаст:
   - программу в меню «Пуск»;
   - ярлык **на рабочем столе** (если отмечено).
4. Удаление — как обычную программу через «Установка и удаление программ».

### Вариант Б — портабельный запуск

Просто скопируйте `SamboTLClient.exe` на компьютер и запустите. Установка не нужна.

## 5. Работа оператора (клиент)

1. Запустите клиент (ярлык «SamboTL Client»).
2. Введите **адрес сервера** — например, `192.168.1.10:8000`
   (IP показывается в панели сервера; на самом сервере можно оставить `127.0.0.1:8000`).
3. Введите **пароль доступа** (его видно в панели сервера).
4. Нажмите **«Подключиться»** — откроется меню рабочих экранов.

Доступные экраны (кнопки):

| Кнопка | Назначение |
|--------|-----------|
| Взвешивание | Список участников, поиск, ввод текущего веса, «прошёл/не прошёл» |
| Жеребьёвка | Создание сеток, стратегия, предпросмотр, распределение по коврам |
| Судейство | Ход схватки: очки, замечания, победитель |
| Табло (ТВ) | Полноэкранное табло для телевизора (таймер, борцы) |
| Расписание | Очередь схваток по коврам |
| Отчёты | Протоколы взвешивания/сетки/итоги в Word/Excel |
| Открыть админку | Вход в админку сервера (для организатора) |

## 6. Требования и устранение неполадок

### Требования
- Windows 10/11 (x64).
- **WebView2 Runtime** для клиента и панели сервера (GUI-окна).
  - На большинстве современных систем уже установлен.
  - Если окно не открывается — установите «Microsoft Edge WebView2 Runtime»
    с официального сайта Microsoft.

### Частые вопросы

**«Сервер недоступен»** — проверьте:
- сервер запущен (индикатор в панели сервера зелёный);
- клиент и сервер в одной локальной сети;
- в клиенте указан правильный IP сервера (показан в панели).

**«Неверный пароль доступа»** — пароль показывает панель сервера (раздел «Доступ»).
Если забыли — смените его там же и сообщите операторам новый.

**Порт занят** — смените порт в панели (например, `8001`) и укажите клиентам
`<IP>:8001`.

**Файервол** — при первом запуске Windows может спросить разрешение на доступ к сети.
Разрешите доступ для `SamboTLServer.exe` (частные сети).

## 7. Сборка из исходников (для разработчика)

```powershell
# все зависимости
pip install -r requirements.txt -r requirements-build.txt

# фронтенд
cd frontend
npm install
npm run build
cd ..

# сборка сервера и клиента + ярлыки
.\packaging\build.ps1

# установщик клиента (нужен Inno Setup)
iscc packaging\client_installer.iss
```

Результат:
- `dist\SamboTLServer.exe` — сервер с панелью;
- `dist\SamboTLClient.exe` — портабельный клиент;
- `dist\installer\SamboTLClientSetup.exe` — установщик клиента.
